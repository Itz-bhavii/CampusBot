# Copilot Templates

This directory contains reusable templates and structures for working with AI coding assistants.

## Contents

- `problem-solving-structure.md` - Step-by-step problem decomposition template for learning by doing (Ruthless Mentor approach)

## Purpose

These templates help maintain consistent, high-quality problem-solving approaches across the project. Reference them when you need structured guidance for tackling complex technical problems.

## Usage

When you need structured problem-solving guidance, share the relevant template with your AI assistant as context.

Example:
```
"Use the problem-solving structure from .copilot-templates/problem-solving-structure.md 
to help me fix [specific issue]"
```
